# Portofolio - Victorio Dalles Rin

Website portofolio pribadi bergaya minimalis dengan dark mode.

## Project

- **Personal Portfolio**: halaman utama
- **Task Tracker**: `projects/task-tracker/`
- **Workout Tracker**: `projects/workout-tracker/`

## Teknologi

- HTML5
- CSS3 (CSS Variables, Flexbox, Grid, Responsive)
- JavaScript (DOM, localStorage)
- Git & GitHub Pages

## Struktur Folder

```
my-portofolio/
├── index.html
├── README.md
├── .gitignore
├── assets/
│   └── style.css
├── image/
│   └── profile.jpg
└── projects/
    ├── task-tracker/
    │   ├── index.html
    │   ├── style.css
    │   └── script.js
    └── workout-tracker/
        ├── index.html
        ├── style.css
        └── script.js
```

## Cara Menjalankan

1. Clone repository ini: `git clone <url-repo>`
2. Buka folder hasil clone di VS Code
3. Buka `index.html` di browser (atau gunakan ekstensi Live Server)
